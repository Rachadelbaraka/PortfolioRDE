MoreFix WebStore

Stage MoreFix · Jan. 2026 – Fév. 2026 · Développeur Full-Stack

B1B2B3
📌 Contexte & Problématique
MoreFix vend des appareils reconditionnés en ligne. Mission : développer le panneau d'administration complet de la plateforme e-commerce avec Next.js et Firebase, intégrant un système de gestion de stock intelligent avec IA.
⚙️ Démarche technique — Panneau d'Administration
  • Tableau de bord : statistiques temps réel (produits, catégories, fournisseurs, valeur stock)
  • Alertes automatiques de stock faible avec notifications
  • CRUD complet : produits, catégories, fournisseurs avec validation de formulaires
  • Badges de statut dynamiques (En stock / Épuisé / Faible stock)
  • Chatbot IA intégré pour assistance à la gestion
  • Table responsive avec recherche, filtrage et défilement mobile
  • Route sécurisée /admin/stock-manager (authentification Firebase)
✅ Résultats mesurés
  • Lighthouse 96/100 (+60 pts)
  • LCP de 4.2s → 1.1s
  • 500+ produits gérés via le panneau admin
  • 0 incident production (3 mois)

Pratiques appliquées

Sécurité dans mes projets

OWASP Top 10 — Couverture
Application des contre-mesures OWASP sur chaque projet web développé.
  • Injection SQL : requêtes paramétrées, ORM typé
  • XSS : échappement Blade (Laravel), CSP strict
  • Broken Auth : Firebase Auth, Laravel Auth
  • IDOR : middleware rôles Spatie, validation permissions
  • Secrets : .env, Vercel secrets, jamais en Git
Authentification & Autorisation
Standards modernes d'authentification implémentés dans les projets.
  • OAuth 2.0 / PKCE (Firebase Auth MoreFix)
  • Spatie Permission : rôles et permissions (BiblioTech)
  • Laravel Auth + middleware de protection de routes
  • Firebase Security Rules (Firestore + Storage)
  • Validation stricte des entrées (Laravel FormRequest)
Infrastructure & CI/CD Sécurisés
Bonnes pratiques DevSecOps intégrées dans les pipelines.
  • HTTPS forcé (Vercel, certificats TLS)
  • Headers sécurité : HSTS, CSP, X-Frame
  • Audit deps : Dependabot + Composer audit
  • Secrets : .env, jamais hardcodés en code
  • Docker : images non-root, réseaux isolés
